This repository is built for Cloudflare Workers + D1. A Vercel deployment can serve this informational page, but the worker APIs and D1 database integration must be deployed with Cloudflare.

  • Cloudflare entrypoint: src/index.ts
  • Cloudflare config: wrangler.jsonc
  • Database schema: schema.sql

To run the application runtime, use npm run dev for local Wrangler development or npm run deploy for Cloudflare deployment.
